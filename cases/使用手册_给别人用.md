# 使用手册：把实测台当成基础设施来用

目标：任何人（同事、合作方、外部评审）拿到一个包，能在半小时内跑出和我们一样的结论；
发现问题能落成一条用例，下一次自动生效。不靠某个人记得怎么做。

---

## 一、三种角色，三条入口

| 角色 | 你要的东西 | 怎么做 |
|---|---|---|
| **只想知道"现在有没有问题"** | 一份结论 | 拿到别人的 `runs\<时间>\summary.html` 直接看，不用跑 |
| **要自己复跑核对** | zip 包 | 解压 → `.\setup.ps1` → `.\run_all.ps1` |
| **要长期做这件事** | git 仓 | `git clone uibc-bench-v0.x.x.bundle` → 改 `harness\` → 提 PR |

## 二、复跑（5 分钟）

```powershell
# 1. 解压分发包（包内带顶层目录，解压后是一个干净的文件夹）
Expand-Archive .\uibc-实测台-0.2.1-20261123.zip -DestinationPath D:\
cd D:\uibc-实测台-0.2.1-20261123

# 2. 准备（克隆被测仓库、建虚拟环境、生成自签证书）
.\setup.ps1

# 3. 全量跑
.\run_all.ps1

# 4. 看结论
start runs\<最新时间戳>\summary.html
python compare_baseline.py runs\<最新时间戳>     # 与基线比：回归 0 才算没退化
```

**没装 Python？** 只用标准库，3.10+ 即可；不需要 Docker、不需要 Java/Go。
**只跑一组**：`python bench.py run --only s06`（单组跑不要更新基线）。
**缺仓库时**：依赖仓库的组会直接报 `BLOCKED` 并提示跑 `setup.ps1`，不会污染结果。

## 三、判定口径（先统一语言，再谈结论）

| verdict | 含义 | 谁能改 |
|---|---|---|
| PASS | 按判据通过 | 判据写在 `cases\场景清单.md` |
| FAIL | 被测方的问题 | 必须附复现命令 |
| WARN | 可疑/已知取舍 | 要写"为什么暂时接受" |
| INFO | 观测值，无判据 | 不许当结论用 |
| BLOCKED | 环境缺东西 | 必须写缺什么 |
| ERROR | 脚本自己错 | 修脚本，不是修判据 |

三条不许破：不许为了变绿放宽判据；不许把 FAIL 静默删掉；不许用 `success:true` 判平台成功。

## 四、发现新问题怎么办（这是"持续改进"的机制）

1. 先确认**是不是自己调用姿势错了**（过去 8 次假失败全是我们脚本写错）。
2. 能在 30 分钟内写成一个用例的，就写用例（`harness\s0x_*.py` 里加一个 `rec(...)`），
   不要只留在聊天里。
3. 用例必须可重复、不写平台、不改被测仓库。
4. 在 `cases\场景清单.md` 登记：场景 / 上线后对应什么情况 / 判据 / 状态。
5. 跑一次全量 → `compare_baseline.py --update` 把它并入基线（这样下次自动盯着）。
6. 外部问题写进 `cases\发现清单_*.md`，标严重度与复现命令，**外发前先内部复核**。

## 五、版本与基线约定

- `VERSION` + git tag 双记录；每个 tag 对应一份 bundle，永久可回溯。
- `baseline.json` = "公认现状"，只在**全量跑过且确认变好**时更新。
- 分发包名带版本与日期，`sha256` 同目录；给别人时连同 `.sha256` 一起给。
- 阈值在 `thresholds.json`，改阈值等于改判据 → 必须在场景清单写理由并进 commit message。

## 六、红线（对外使用时）

- 信通院平台：只读 GET + 无状态 resolve 查询；不注册、不写入、并发 ≤8。
- 我方仓库：外人视角克隆，不改不推。
- 发现的问题：先内部复核再定口径；对外措辞只描述"观察到什么"，不推断意图。

## 七、现在还做不到的（别让使用者误以为全能）

1. 只在 Windows + Python 3.12/3.13 跑过；Linux 未验证 → 拿到 Linux 上跑要预期有差异。
2. 没有 CI，不会自动夜里跑；靠人触发。
3. 判定未过第三方独立复评（LGD-Eval）。
4. 平台写链路（注册/审批/撤销）没测，因为没有凭据也不该测。
5. `did:cn` 客户端不在公开仓库内，我们只能测到"缺它"这件事本身。
